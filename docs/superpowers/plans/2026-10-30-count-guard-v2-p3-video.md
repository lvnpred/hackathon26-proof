# Count Guard v2 · P3 Video Detection Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Two video checks run on stand-in clips and land on the chart with frames as proof. The tray check
runs before surgery: the tray plan comes from the procedure template the doctor confirms at Send to theatre.
The saline set-up check runs on the ward, on Iyer's `start_end` saline task. Both run offline without a key.

**Architecture:** Procedure and ward set-up templates are cited sample-data JSON files. A pure loader,
`journey/procedures.py`, reads them. Send to theatre writes `tray.planned` from the template. A video
upload goes to one new route, `POST /journey/episodes/{id}/video` (`journey/video_api.py`), with
`check: tray | setup`. Detection runs through the P2 model seam (`journey/live.py`, new `segment_clip`).
With a key it calls SAM 3.1 through the existing `SamAdapter`. Without a key it reads a prepared result
keyed by the clip's name. A pure module, `journey/video.py`, turns detections into "planned vs seen" rows.
Frames are cut locally with ffmpeg and stored as `photo.added {purpose: "frame"}`. The check is written as
`tray.checked` or `setup.checked`. A missing item is flagged and never blocks: the surgeon decides for the
tray, the nurse for the set-up (as D9). The P1 swab count is unchanged: manual first, camera second.

**Tech Stack:** FastAPI + pydantic v2 (multipart), SQLite ledger, pytest, ffmpeg/ffprobe (frame cutting;
live clip conversion), SAM 3.1 adapter (`app/adapters/sam.py`, live only); React 18 + Vite, Node built-in
test runner; Pillow + ffmpeg for the stand-in clips.

**Spec:** `docs/superpowers/specs/2026-10-29-count-guard-v2-patient-states-design.md`. Sections: P3, D3,
D6 and "Sample data", D9, D11, D12, D14, the Data table rows `tray.planned` / `tray.checked`, and
anti-goals. Ledgers: P1 `.superpowers/sdd/2026-10-29-count-guard-v2-p1-states/progress.md` and P2
`.superpowers/sdd/2026-10-30-count-guard-v2-p2-voice-photo/progress.md`. The P2 rulings P2-R1, R3, R4,
R5, R15, R17 and R20 bind this plan too. This plan closes the P1 deferred minor on `StateIn.procedure`.

## Out of scope (decided)

- Counting swabs by the tray check. Swabs are counted by the existing swab count (P1 manual, v1 camera). The
  tray check covers instruments only. Cost if wrong: one more concept row; the template already carries the
  swab totals.
- Editing the tray plan before sending. The doctor confirms the template as published. Cost if wrong: a
  per-item untick on the preview list later.
- A queue nudge for a flagged tray. The flag shows on the theatre cards (nurse and doctor) and on the chart.
- Keeping the raw clip. The upload is deleted after the frames are cut, as P2 did with raw audio.
- Live SAM on the owner's real surgical clips during the build. Only the owner runs live (D11).

## Review Focus

1. A clip name that is not a safe stem (`../../x.mp4`, `Tray Hernia.MP4`), or an unknown name with no key.
   Nothing outside `journey/prepared/` is read. The check is written with `match "none"`, no frames, and
   `clip ""`. Nothing is refused or blocked. Test in Task 3.
2. A tray check outside theatre, after surgery began, or with no `tray.planned`, gives 409 and writes
   nothing. A flagged tray never stops Surgery began, the swab count or Back to ward. Tests in Task 3.
3. A live SAM reply with low-score boxes, an id switch on a still tray, or a label that was not asked.
   Each concept is counted as its largest number of distinct ids in one frame, among boxes with score ≥
   `settings.low_confidence` (or no score). Labels not asked are ignored. Test in Task 2.
4. ffmpeg is missing or cannot read the clip when frames are cut. The check is still written, with
   `frame_ids: []`. Its `why` ends `" No frames could be cut from the clip."`. No 500. Test in Task 3.
5. A set-up check on a done or closed task, on a task without video proof, or on a task with no set-up list
   gives 409. A tray check with a `task_id`, or a set-up check without one, gives 422. Tests in Task 4.

- Produces (`video.py`, pure):
  - `expected_for_tray(plan) -> list[{"concept", "names", "planned"}]`: the instruments that have a concept, grouped by concept in first-seen order. `planned` is the sum of `qty`; `names` lists the item names.
  - `unchecked_for_tray(plan) -> list[str]`: the names of instruments with no concept.
  - `expected_for_setup(key) -> list[...]`: the same shape, from `SETUP_TEMPLATES[key]["items"]`.
  - `summarize(records, fps: int, min_score: float, concepts) -> dict[str, {"count": int, "at_s": float | None}]`: one entry for each asked concept. Count = the largest number of distinct `object_id`s in one frame, among records with that label and `score is None or score >= min_score`. `at_s` = the first frame with that count ÷ fps. A concept never seen gives `{"count": 0, "at_s": None}`. Labels not asked are ignored (Review Focus 3).
  - `compare(expected, detections: dict | None) -> {"rows": [{"concept","names","planned","seen","at_s"}], "missing": [concept], "match", "why"}`. With `detections None`: `seen None`, `match "none"`. Missing = rows with `seen < planned`. `match` is `"mismatch"` if anything is missing, else `"ok"`.
  - Exact `why` copy: ok → `"Every planned item was seen in the clip."`; mismatch → `"Not seen in the clip: " + "; ".join(f"{concept} (planned {p}, seen {s})") + "."`; none from `"none"` → `"The clip was not checked: no model key and no prepared result for this clip."`; none from `"failed"` → `"The clip was not checked: the video model did not answer."`. Constants `NOT_CHECKED`, `NO_ANSWER`, `NO_FRAMES = " No frames could be cut from the clip."`.
  - `frame_times(rows) -> list[float]`: the distinct `at_s` of rows with `seen > 0`, sorted, at most 6. When every row has `seen == 0`, it is `[0.0]`. With no detections it is `[]`.

- Produces (`live.py`): `MAX_LIVE_SECONDS = 120`, `LONG_CLIP = "The clip is longer than 2 minutes. Trim it, then upload it again."`, and `segment_clip(settings, clip: Path, filename: str, concepts: list[str]) -> {"detections": dict | None, "source"}`.

Otherwise run `to_sam_clip` into a temp dir at `settings.sam_fps`, then `SamAdapter(settings).segment_video(out, concepts)`, then `summarize(..., settings.sam_fps, settings.low_confidence, concepts)`. Return `source "sam-3.1"`. `httpx.HTTPError`, `RuntimeError`, `OSError` or `ValueError` give `{"detections": None, "source": "failed"}`.
