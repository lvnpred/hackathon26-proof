# SpokenGuide

The numbered "What to say" list: each step is a spoken command and an example, and the one being dictated is highlighted.

**Consumer provides:** `steps` (`{say, example}` — `say` is the code word exactly as spoken, ending in "…"; `example` is real, short content) and `active` (the 1-based step being dictated, 0 for none).

- The spoken words match the sheet's section headings, so people learn the commands by reading the paper.
- The active step takes `sun-soft` and its number turns `sun-text`; finished steps get a leaf tick.
- Keep it to the sections the document really has; seven is the clinic prescription.
