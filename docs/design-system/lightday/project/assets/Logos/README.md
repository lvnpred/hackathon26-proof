# Logos

- `lightday-mark.svg` — The mark for light grounds (`paper`, `surface`): sun `#F2A93B`, horizon in ink `#1C1A17`. Two fixed inks; it does not recolour.
- `lightday-mark-reverse.svg` — The mark for dark grounds (Dusk `paper`, photos): sun `#F5B54A`, horizon `#F4EEE3`.
- `lightday-app-icon.svg` — The app icon and favicon: the mark on an ink tile with `radius-xl` corners. Use it as is; never re-crop the mark out of it.

Set the wordmark "lightday" as live text beside the mark (Figtree 800, lowercase, letter-spacing -0.02em). There is no wordmark image. In React, `Lightday.Mark` draws the mark with the theme's `sun` and `ink` tokens.
