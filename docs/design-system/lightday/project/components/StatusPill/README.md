# StatusPill

One plain word of state with a dot, on its tone's soft tint.

**Consumer provides:** `children` (one word: Ready, Recording, Saved, Synced, Open) and a `tone`: `ready` (leaf), `recording` (record), `info` (sky), `sun` (in progress / per-use), `neutral`.

- The word carries the meaning; colour only supports it, so the pill reads the same to colour-blind users.
- One pill per row or bar. Never use a pill as a button.
