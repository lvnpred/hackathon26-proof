# AppTile

One app in the Lightday suite launcher: what it is for and what it costs to use.

**Consumer provides:** `name` (one or two plain words for the job), `job` (one sentence, what it does for you), `price` (per use: "₹[price] per prescription" — never a monthly plan), an optional `status`, and `href`.

- Tiles sit in a wrapping grid, 220px minimum, `space-4` gaps.
- The price line is `sun-text` and always per use. No "Upgrade", no trial countdown.
- The tile letter sits on a `sun` square with `on-sun`; never draw a picture icon per app.
