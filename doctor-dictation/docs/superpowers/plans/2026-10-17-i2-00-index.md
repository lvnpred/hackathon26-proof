## 4. Contract amendments (to i1-00 section 4)

### 4.1 Rx row JSON (additive; existing fields keep their names and types)

| Field | Was | Now | Owner |
|---|---|---|---|
| `generic` | "The generic when `name` is a brand ... else `""`. Screen only." | The lexicon match of every row that has one: a brand -> its generic; a generic-named or alias-named row -> its canonical. `""` when `lexicon_match` is `""`. **Screen and print.** Recomputed server-side (`correction.RECOMPUTED_ROW_FIELDS`, unchanged guard: `""` when `_canonical_lookup(name)` no longer equals `lexicon_match`) | I2-a |
| `did_you_mean` | (new) | For an `unknown-medicine` row only: the top sound-alike spelling when it is a clear winner (score >= 0.9, at least 0.05 ahead of the next different generic, no curated look-alike twin); else `""`. A suggestion only | I2-a |
| `did_you_mean_generic` | (new) | The generic of `did_you_mean` (`""` for a clinic name with no generic) | I2-a |
| `schedule` | (new) | `"H"`, `"H1"`, `"X"` or `""`, from the generics list through `lexicon_match`. Information only: never changes `status`, never blocks Save | I2-d |

`correction.DERIVED_ROW_FIELDS` becomes `("generic", "heard", "lookalike", "dose_note", "source", "did_you_mean", "did_you_mean_generic", "schedule")`. `did_you_mean`, `did_you_mean_generic` and `schedule` join `RECOMPUTED_ROW_FIELDS` (they depend on the name, the status and the lexicon match only; the page never sends them back). `ops._regrounded` drops them through the tuple (`core/ops.py:81`).

**Built (differs from the two sentences above):**
- `DERIVED_ROW_FIELDS` is `("generic", "schedule", "heard", "lookalike", "dose_note", "source", "did_you_mean", "did_you_mean_generic")` (`core/correction.py:270`): `schedule` is second, not last.
- Only `generic` and `schedule` are in `RECOMPUTED_ROW_FIELDS` (`core/correction.py:291-294`). The two Did you mean fields live in a separate tuple `DID_YOU_MEAN_FIELDS` (`core/correction.py:273`), so one computation per row serves both (`:404`). Reason: computing them twice cost 72.6 ms for 8 rows; a bounded cache and one pass gave 32.6 ms cold, 14.0 ms warm (I2-a fix round).
- The inline Did you mean rule is stricter than the 0.9 / 0.05 rule above. It also needs a text-only letter ratio of at least 0.7, at least 6 letters in the suggested name, and no name of a different generic that starts with the typed letters (`core/rowcheck.py:13-15`, `:159-170`). 0.8 was rejected: it drops the required `croissin` to `Crocin` (text ratio 0.714) and `citrizene` (0.737); wrong cases measured 0.5 to 0.667.

## 7. Risks

1. **The printout changes (D2).** A pharmacist sees a new line. A wrong generic link would now be printed. Mitigation: the generic comes only from the reviewed core list (five checks, `lexicon_import.py:1-16`); a hand-edited name loses it (`correction.py:270-274`).
2. **One-tap Did you mean is a look-alike risk** (backlog card (c), `2026-10-17-i1-backlog-suggestion-ideas.md:36-41`). Mitigation: shown only for a clear winner and never for a curated look-alike pair; one tap answers the NAME question only; Undo restores the row.
3. **Invented history.** An LLM may add "no h/o diabetes" that nobody said. Mitigation: prompt rule, the "unheard words" note, length caps. It is a heuristic: it can miss a rewording and can flag a correct synonym.
4. **Time zone** (Q7). No code change fixes a UTC container.
5. **Voice input sends a short audio clip to the speech engine,** like dictation does. No new provider.
6. **Government data licence.** The code decides no licence (flags only, `build.py:147-153`). The owner confirms the reuse terms (Government Open Data terms) before the real sync.
7. **New generics as lexicon names** widen `correct_drugs` rewrites. Mitigation: brandless canonicals only after a clinician review sheet, curated look-alike pairs for every computed twin (Iteration 1 measured 24 of 104 new canonicals with a computed twin, for example Daunorubicin/Doxorubicin, Dopamine/Dobutamine), and the ordinary-sentence gate (`tests/test_ordinary_sentences.py`).
