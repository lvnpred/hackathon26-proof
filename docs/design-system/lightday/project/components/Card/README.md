# Card

A bordered `surface` that groups one job on the screen: the mic and its prompt, the spoken guide, a list.

**Consumer provides:** `children` and an optional `title` (written in sentence case, shown in `label` caps). `tone="sunk"` sets it into the page instead of lifting it.

- Cards separate with a `line` border, not a shadow. Only the document sheet has a shadow.
- Do not nest cards. Do not colour a card's edge to mark it.
