# I1-e3: Medication Row UI, "Spell it"

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A "Spell it" button on rows that need a name decision opens an inline panel under that row only; choosing a suggestion or typing a name re-checks just that row through `POST /api/v1/rx/check-row` and replaces only that row's fields, with honest errors and a working Undo.

**Architecture:** Pure helpers (`afterSpell`, `cleanTyped`, `typedProblem`, `errorText`) join `rxstate.js`; the panel and the request live in `rxview.js`; `app.js` gets two small edits (undo branch, three more hooks). One guarded script makes every edit.

**Tech Stack:** vanilla JS, pytest + node, Playwright MCP tools.

**Spec:** `docs/superpowers/plans/2026-10-16-medication-name-accuracy.md` "Iteration 1" sections 1, 4 and 5; contracts `docs/superpowers/plans/2026-10-16-i1-00-index-and-contracts.md` sections 4.4 (request and response) and 4.5.

**Assumptions about earlier plans:** I1-e and I1-e2 are applied (11 tests in `tests/test_frontend_rxrow.py`). I1-d provides `POST /api/v1/rx/check-row` as in contract 4.4: request `{row, transcript, age_sex}`, response `{row, suggestions}`, 400 for a bad row, session-protected like other `/api/v1` routes (an expired session is sent to the login page by `auth.js`). Until I1-d exists, the browser check stubs the route (Task 3 says how).

## Global Constraints

- No `git commit` or `git push`. Baseline first: `.venv/bin/python -m pytest tests/ -q`, note the count, expect count + 4.
- A name the doctor typed is never trusted: the row always goes through check-row, and the answer's status decides the state.
- "Say the letters (later)" is a disabled button with the title "Planned for later, only if it proves accurate"; no voice code.
- The page holds only the latest dictation as `state.transcript` (after a correction dictation that is the correction, not the whole visit; for a reopened document it is empty). The request sends what the page holds, as the contract says; `heard` is therefore best-effort.
- Browser checks use `DB_PATH` on a temp file (memory note "Single mode writes the real dev DB").

## Review Focus

- The server answers 500, 400, a timeout, or not at all: the row stays as it was and the panel says so (`test_the_panel_follows...`, manual 5 and 6).
- The doctor edits or deletes the row while the check is in flight: the late answer must be dropped (`r.req !== tok`; manual 9 and 10).
- A typed name that is not in the list, or a dose problem that remains, must not become "Confirmed by you": `test_spelling_settles_name_questions_only`.
- Typing in the panel must not mark the sheet changed (that would disable Print): `e.stopPropagation()` on the panel; manual 2.
- Letters said one by one ("p r e d n i s o l o n e") become one word; names with a space ("Vitamin D3") stay: `test_typed_names...`.

## Decision: when does "Use this" mean "Confirmed by you"?

The contract says a spelled row is `you`. The doctor chose the **name**, so questions about the name (`verified`, `unverified-name` because the typed word is not in the transcript, `lookalike-check`) are answered and the row is confirmed (`state.confirmed`, so `confirmed_rows` carries it). Questions the choice cannot answer stay open: `unknown-medicine` (the list does not know the typed name), `dose-check` and `unverified-strength` (the dose is a separate decision). Those rows stay `confirm` or `dose` with the note `Name changed to "X". It still needs your decision.` The owner accepted this narrowing on 2026-10-16 and contract 4.5 now says so (index, Decisions).

How it behaves: Spell it opens one panel (any other closes) as a `<tr class="rx-spell-row">` right under the row, and asks check-row for suggestions with the row as it is. The answer replaces that row's cells, status, `lexicon_match` and extra fields; an undo record holding the row as it was is pushed; the existing Undo button restores it. Escape or Close closes the panel and returns focus to Spell it.
